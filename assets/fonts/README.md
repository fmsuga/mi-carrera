# Tipografías locales

Archivos originales sin modificar, distribuidos junto a sus licencias SIL Open Font License 1.1:

- `InterVariable.woff2`: Inter, proyecto de Rasmus Andersson y colaboradores. Licencia en `OFL.txt`. Fuente: https://github.com/rsms/inter/tree/master/docs/font-files
- `SourceSerif4Variable.woff2`: Source Serif 4, Adobe. Licencia en `SourceSerif-LICENSE.md`. Fuente: https://github.com/adobe-fonts/source-serif/tree/release/WOFF2/VAR

Se sirven desde `assets/fonts/`; no se requiere conexión a un proveedor de fuentes.
